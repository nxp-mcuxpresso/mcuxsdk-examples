# coex_wifi_a2dp_source

## Overview
The example demonstrates the coexistence of Bluetooth A2DP source (edgefast_open) and Wi-Fi.

This document provides step-by-step procedures to build and test the example, and also instructions for running the included sample applications.

## Supported Boards
- [MIMXRT1060-EVKC + IW612](../../_boards/evkcmimxrt1060/coex_examples/coex_wifi_a2dp_source/example_board_readme.md)
