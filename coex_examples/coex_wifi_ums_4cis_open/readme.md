# Coex Wi-Fi UMS 4CIS

## Overview
This application demonstrates Wi-Fi and Bluetooth LE Audio coexistence.
It combines the Wi-Fi CLI functionality with the Unicast Media Sender (UMS) 4CIS LE Audio profile.
