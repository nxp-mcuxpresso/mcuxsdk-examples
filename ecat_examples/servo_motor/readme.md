# ecat_servo_motor

## 1. Overview

A CiA402 compliant EtherCAT servo drive running entirely on a single core: the EtherCAT
communication (SSC) and the motor control loop share the same CPU.

| Item | Value |
|------|-------|
| EtherCAT profile | CiA402 (drives and motion control) |
| Cores used | 1 |
| Motors supported | 1 |
| Encoder | Quadrature encoder |
| MainDevice used for the demo | TwinCAT 3 |

> For a dual core variant with up to two motors and absolute encoders, see
> [dual_cores_servo_motor](../dual_cores_servo_motor/readme.md).

> **MainDevice options:** this document uses TwinCAT 3 as the EtherCAT MainDevice. An all NXP
> setup is also possible by using the SOEM based MainDevice example
> [soem_servo_motor_rt1180 (bm)](https://docs.mcuxpresso.nxp.com/mcuxsdk/latest/examples/soem_examples/soem_servo_motor_rt1180/bm/readme.html)
> on a second board.

> **Important:** the project cannot be built as shipped. The SSC source code must be generated
> and patched first - see [2. Build preparation](#2-build-preparation).

## 2. Build preparation

Throughout this chapter `<SSC_DIR>` means:

```
<mcuxsdk>/boards/<board>/ecat_examples/servo_motor/<core>/SSC
```

### 2.1 Generate the SSC source code

1. Download the Slave Stack Code Tool (SSC Tool V5.13) from the Beckhoff website and install it.
2. Create an empty output folder for the files generated by the SSC tool.
3. Open the SSC tool and import the configuration:
   `File` > `New` > `Import`, then select `<SSC_DIR>/servo_motor.xml`.
4. Select the SubDevice description file: `Custom` > `NXP ECAT...` > `OK`.
5. Save the project: `File` > `Save` (into the folder created in step 2).
6. `Project` > `Create new Slave Files`, set `Source Folder` to that folder, then click `Start`.

The ESI file and the SSC source code are now in the output folder.

### 2.2 Copy the generated code into the SDK

1. Delete the existing `<SSC_DIR>/Src` folder.
2. Copy the generated `Src` folder into `<SSC_DIR>/`.

### 2.3 Apply the patch

Change the working directory to `<SSC_DIR>`, then:

**Linux**

```sh
sudo apt-get install dos2unix
dos2unix Src/*
patch -d ./ -p1 -i ./CiA402-combine-the-SSC-slave-with-ec_pmsm-support.patch
```

**Windows**

1. Download the tools:
   - Windows Patch utility: http://gnuwin32.sourceforge.net/downlinks/patch-bin-zip.php
   - Dos2Unix/Unix2Dos converters: https://sourceforge.net/projects/dos2unix/
2. Convert the patch to DOS line endings and apply it:

```bat
$(Dos2Unix/Unix2Dos-DIR)\bin\unix2dos.exe CiA402-combine-the-SSC-slave-with-ec_pmsm-support.patch
patch.exe -d ./ -p1 -i ./CiA402-combine-the-SSC-slave-with-ec_pmsm-support.patch
```

### 2.4 Build and flash

Build the project and download the image, following the board specific steps in the board
readme listed in [5. Supported boards](#5-supported-boards).

## 3. Expected output

```
Start the SSC servo_motor example...
```

The servo drive is now waiting for the EtherCAT MainDevice to connect.
