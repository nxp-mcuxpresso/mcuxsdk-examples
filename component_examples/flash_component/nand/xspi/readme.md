# flash_component_nand_xspi

## Overview

NAND flash demo shows the use of the NAND flash component to erase, program, and
read an external NAND flash device over an SPI interface.

## Supported Boards
- [FRDM-IMXRT700](../../../../_boards/frdmimxrt700/component_examples/flash_component/xspi_nand/example_board_readme.md)
