# flexio_a-format_PWM_trigger

## Overview
The a-format_PWM_trigger example shows how to use flexio A-format driver in sync way:

In this example, a flexio simulated A-format connect to the encoder through RS-485, the board
will send requests triggered by the PWM to and receive responses from the board.

## Supported Boards
