# Board specific readme

## Hardware Requirements
- EVKB-MIMXRT1170 board
- Murata 2EL M2 module (IW612)
- USB flash drive with WAV audio files
- Micro USB cable

## Board Settings
- Connect the Murata 2EL M2 module to the M.2 connector on the board.
- Connect a USB flash drive containing WAV files to the USB host port.
