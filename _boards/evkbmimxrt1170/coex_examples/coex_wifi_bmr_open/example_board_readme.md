# Board-specific notes for coex_wifi_bmr_open on evkbmimxrt1170

## Hardware Requirements
- evkbmimxrt1170 board
- IW612 module (Murata 2EL M2)
- Headphones or speakers connected to the audio jack (WM8962 codec)

## Build Configuration
Always use `flexspi_nor_release` for coex apps to get optimal Wi-Fi throughput.
