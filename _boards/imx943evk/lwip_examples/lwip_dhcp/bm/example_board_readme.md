Hardware requirements
===================
- Micro USB cable
- IMX943-EVK board
- J-Link Debug Probe
- 12V~20V power supply
- Personal Computer

Board settings
============
This example uses NETC ENETC0 (ETH2/J25) 1G port in default. To choose other port, define macro SELECT_MAC_PORT as another mac port in lwip_netc_port.h.
