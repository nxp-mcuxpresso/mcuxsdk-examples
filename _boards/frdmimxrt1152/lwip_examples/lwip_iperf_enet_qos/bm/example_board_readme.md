Hardware requirements
=====================
- FRDM-IMXRT1152 board
- USB Type-C cable
- RJ45 network cable
- Personal Computer

Board settings
==============
- Connect the USB Type-C cable to the FRDM-IMXRT1152 USB debug connector.
- Use the 10/100 Ethernet RJ45 port (J55).
- Set JP2 to position 1-2.
