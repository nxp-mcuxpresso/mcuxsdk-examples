Overview
========
This application demonstrates use of certified NXP Safety Library 4.4 which meets the IEC60730 class B standard.

More information
================
- All important documents (library/application user's guide, release note and certificate) are in \docs\safety\ folder.
- For more information see webpage: www.nxp.com/iec60730.

Running the demo
================
- Follow IEC60730B example user guide in \docs\safety\ folder.
