General Example Settings
========================
Hardware requirements
---------------------
- USB Type-C cable
- MCIMX91-QSB board
- 12V~20V power supply
- Personal Computer

Prepare the Demo
---------------
1.  Connect 12V~20V power supply to the board, switch SW301 to power on the board.
2.  Connect a USB Type-C cable between the host PC and the J1401 USB DBG port on the target board.
