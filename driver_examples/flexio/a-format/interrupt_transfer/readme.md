# flexio_a-format_interrupt_transfer

## Overview
The flexio_a-format_interrupt example shows how to use flexio A-format driver in interrupt way:

In this example, a flexio simulated A-format connect to the encoder through RS-485, the board
will send requests to and receive responses from the board.
