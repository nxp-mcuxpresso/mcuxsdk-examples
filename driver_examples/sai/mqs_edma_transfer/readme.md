# sai_mqs_edma_transfer

## Overview
The sai_mqs_edma_transfer example shows how to use SAI driver with EDMA to playback audio via MQS.

In this example, one SAI instance playbacks the audio data stored in flash/SRAM using EDMA channel, and MQS converts the audio stream to PWM signals.

## Supported Boards
