# sramctl_single_bit

## Overview

The SRAMCTL single-bit example demonstrates SRAMCTL **single-bit** error injection and ECC correction.

The purpose of this example is to show how to configure SRAMCTL initialization and error injection, and how to verify that a **correctable** ECC event is detected (`SGLERR`) and counted (`ECCNT`).

## Supported Boards
- MIMXRT2660-EVK
