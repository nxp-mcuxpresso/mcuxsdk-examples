# temp_measure

## Overview
The temp_measure example simply shows how to use the tempsense driver APIs in the SDK.

In this example, the on-die temperature can be obtained using the tempsense module and
adc module.

## Supported Boards
- [FRDM-MCXE31B](../../../_boards/frdmmcxe31b/driver_examples/tempsense/temp_measure/example_board_readme.md)
