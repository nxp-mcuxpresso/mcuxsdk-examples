# ethosu_apps

## Overview

The example `ethosu_apps` accomplishes the inference for `conv2d` op model. The inference engine is TensorFlow Lite Micro.

## Toolchains supported

- IAR Embedded Workbench for ARM
- ArmGCC - GNU Tools ARM Embedded
