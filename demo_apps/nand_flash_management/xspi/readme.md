# nand_flash_management_xspi

## Overview

NAND flash management demo shows file system management on an external NAND flash
device over an SPI interface using the DHARA flash translation layer, the
FatFs file system, and FreeRTOS, driven by interactive shell commands.

## Supported Boards
- [FRDM-IMXRT700](../../../_boards/frdmimxrt700/demo_apps/nand_flash_management/xspi/example_board_readme.md)
