# ota_mcuboot_basic

## Overview
This `ota_mcuboot_basic_iped_remap` is customized `ota_mcuboot_basic` example demonstrates usage of IPED encryption combined with flash remapping feature. It requires configured `mcuboot_opensource` for Encrypted XIP mode utilizing flash remap (`CONFIG_BOOT_MODE_ENCRYPTED_XIP_REMAP`).

## Supported Boards
- [FRDM-RW612](../../_boards/frdmrw612/ota_examples/ota_mcuboot_basic/example_board_readme.md)
- [RD-RW612-BGA](../../_boards/rdrw612bga/ota_examples/ota_mcuboot_basic/example_board_readme.md)
