# els_pkc_pqc

## Overview
The ELS PKC application provides examples which demonstrate usage of post-quantum cryptography (PQC) algorithms with the ELS PKC crypto library:
- PQC operations MlDsa (ML-DSA-44, ML-DSA-65, ML-DSA-87)

## Running the demo
The log below shows the output of the demo in the terminal window:

============================

ELS PKC PQC example END
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
